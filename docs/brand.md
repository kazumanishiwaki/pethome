# pethome ブランドガイド

## 約束
好きな部屋も、この子との暮らしも、あきらめない。

## 見せ方
- ホテルの私室のような静けさを参考に、部屋でくつろぐ時間を伝える。
- パールホワイト #f9f7f5、墨色 #272326、グレージュ、控えめなローズ #95756f。
- ロゴは小文字のセリフ書体。日本語は見出しと本文の強弱をつける。
- 過剰な金色、ネオン、肉球装飾、架空の認定・会員数を足さない。
- 写真は生成イメージとして扱い、実績や特定製品の再現とは表示しない。

## 声
生活を責めず、好みを尊重する。インテリアと実際の過ごしやすさを両立して考える。
条件を調べる負担を整理する方針を示すが、受付前に提供中とは表示しない。

## 維持する実装
4問・8結果のローカルチェック、留守の時間に応じた確認事項、契約・決済なし、生成画像の注記、未確定価格の非表示。
公開本文はビルド時にレビュー用資料へ集約する。

## 検証
この方向性はブランドの仮説であり、好みや有料申込率を実測したものではない。
正式な集客時は見た目の評価だけでなく、サービス理解と相談意向を確認する。
